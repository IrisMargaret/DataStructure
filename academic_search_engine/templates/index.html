    系统结构与数据结构说明

    主模块 / 子模块层次、对外接口契约，以及倒排索引、Trie 树、布尔解析、TF-IDF、 词干提取等课程考察点的设计与复杂度说明。

    一、模块层次与职责

    • ① 核心算法层 core/ —— 纯手写，无第三方依赖
      子模块：paper.py 论文实体/内容键 · preprocessor.py 中英分词/停用词/词干 · stemmer.py Porter 词干提取 · inverted_index.py 倒排索引/归并检索/TF-IDF · trie.py 前缀补全 · query_parser.py 递归下降布尔解析 · translator.py 中英互译词典 · keyword_extractor.py 关键词提取
    • ② 文档解析入库 ingest/
      子模块：pdf_extractor.py PDF 文本/元数据 · text_parser.py 纯文本拆解（中英版式） · document_parser.py 统一拆解流水线 · zip_importer.py ZIP 批量（防穿越） · encodings.py 编码探测/乱码还原 · clean_text.py 噪声过滤
    • ③ 数据采集 crawler/
      子模块：registry.py 源注册表 + 跨源内容去重 · arxiv_crawler.py arXiv 源 · openalex_crawler.py OpenAlex 源（含 language:zh 中文文献）
    • ④ 拆解 Agent agent/ —— 可选，配置见 .env
      子模块：llm.py OpenAI 兼容客户端 · prompts.py 提示词与输出契约 · paper_agent.py 元数据精修与回退
    • ⑤ 检索服务门面 service/
      子模块：search_service.py 组合根对象：线程安全、原子持久化、统一入库流水线
    • ⑥ Web 接口层 web/ + templates/ + static/
      子模块：__init__.py 应用工厂 · routes.py 薄路由 · index.html / style.css / app.js 前端三视图
    • ⑦ 数据存储 data/
      papers.json 论文元数据（keywords/file/language/source）· stopwords.txt 停用词 · bilingual.json 中英互译词典 · papers_files/ 上传原文归档（运行时生成）

    三、核心数据结构与算法

    以下为课程考察点的内存形态与复杂度。

    倒排索引 · Inverted Index

    term → List<Posting(paper_id, tf, positions)> transform → [ (12, tf=3, pos=[0,6,9]), (45, tf=1, pos=[2]), … ] network → [ (12, tf=2, pos=[1,8]), (45, tf=5, pos=[0,3,4,7,11]), … ] graph → [ (12, tf=1, pos=[5]), … ] · 词条按词干合并变体（transformer / transformers → transform） · df = 列表长度；tf = 篇内频次；positions 用于短语相邻匹配

    AND 归并检索（最短优先，O(n)）

    查询：graph AND neural AND network Posting 长度：graph=2, neural=4, network=5 → 按升序归并：2 → 4 → 5 双指针求交：先以最短列表(2)为基准，与 neural(4) 求交得候选，再与 network(5) 求交 每轮 O(len(a)+len(b))，总体线性；任一列表为空立即返回 ∅

    Trie 前缀树（模糊提示 Top-K）

    root └─ t → r → a → n → s → f → o → r → m* freq=108（transform） └─ …（transformers / transformer-based / transfer …） 每节点：children 字典 + freq 计数器；键入前缀后 DFS 收集完整词并按 freq 降序返回 Top 10

    布尔查询文法（递归下降）

    or_expr := and_expr (OR and_expr)* and_expr := not_expr (AND? not_expr)* // 相邻词 = 隐式 AND not_expr := NOT not_expr | atom atom := '(' or_expr ')' | 词条 | "短语" 求值：AND → 交集 &，OR → 并集 |，NOT → 全集 − 差集

    TF-IDF 相关性权重

    score(q, d) = Σt∈q∩d tf(t,d) × idf(t)，　 N + 1df(t) + 1 的对数再加 1：
    idf(t) = ln( (N+1) / (df(t)+1) ) + 1，　N = 总论文数，df = 词条文档频率

    Porter 词干提取（手写）

    transformers / transformer → transform studies → studi · convolutional → convolut · relational → relat 检索 "transformer" 与 "transformers" 等价；界面保留原词展示（display 映射）

    关键词自动提取（入库时）

    对每篇论文：score(term) = (标题 tf × 2 + 摘要 tf) × idf(term) 取 Top 8 作为该论文 keywords，并入索引文本 → 关键词亦可被检索
