    结构与说明

    系统架构、核心数据结构与算法、接口与扩展方式。

    系统架构

    1. web/ Flask 薄路由层（JSON API）
    2. service/ 检索服务门面：组合算法与数据，线程安全，唯一入口
    3. core/ 核心算法：倒排索引 · Trie · 布尔解析 · TF-IDF · 词干 · 互译词典 · 关键词提取
    4. ingest/ 文档入库：PDF/纯文本/ZIP 拆解、编码修复、去噪
    5. crawler/ 数据采集：arXiv / OpenAlex，跨源去重
    6. agent/ AI 精修（可选）：OpenAI 兼容接口，失败自动回退规则拆解

    依赖方向：web → service → core / ingest / crawler / agent；算法层全部手写无第三方依赖。

    数据结构与算法

    倒排索引 Inverted Index
    词干 → 倒排表 Posting(论文ID, 词频, 位置列表)；变体合并（transformer/transformers → transform）。
    多词 AND 归并
    按倒排表长度升序，双指针两两求交，整体线性 O(n)。
    Trie 前缀树
    输入前缀 → DFS 收集完整词，按词频返回 Top 10；未命中自动子串包含兜底。
    布尔查询（递归下降）
    AND / OR / NOT / 括号 / 引号短语；AND→交集、OR→并集、NOT→全集差集。
    TF-IDF 相关度
    score(q, d) = Σ对 q 与 d 共有的词条 t  tf(t, d) × idf(t)
    idf(t) = ln (N + 1df(t) + 1) + 1，　N = 论文总数，df(t) = 词条 t 的文档频率
    Porter 词干
    手写实现：检索 transformer 与 transformers 等价，界面保留原词展示。
    关键词自动提取
    入库时按「标题词频×2 + 摘要词频」× IDF 取 Top 8，并入索引可检索。
    倒排索引结构示例 
    transform → [(12, tf=3, pos=[0,6,9]), (45, tf=1, …)]
network   → [(12, tf=2, pos=[1,8]), (45, tf=5, …)]
graph     → [(12, tf=1, pos=[5]), …]

    接口与扩展

    核心接口契约：

    接口模块说明
    Preprocessor.tokenize(text, …)core中英分词 → 词干序列（可选位置/原词）
    InvertedIndex.build / add_papercore构建 term → List<Posting>
    InvertedIndex.search(query, mode)core自动识别布尔/AND，返回结果与剖析 trace
    Trie.suggest(prefix, top_k)core前缀补全，按词频降序
    QueryParser.parse(q) → ASTcore递归下降布尔语法
    document_parser.parse_file(path, use_ai)ingestPDF/纯文本统一拆解入口
    paper_agent.refine_metadata(text, meta)agentLLM 精修，失败回退规则结果
    SearchService.search / add_* / …serviceWeb 层唯一入口（RLock）

    扩展方式：

    • 新增数据源：在 crawler/registry.py 注册一个「抓取函数 → 论文字典列表」的源即可。
    • 更换 AI 服务商：任意 OpenAI 兼容服务，在「AI 设置」填写地址 / Key / 模型即可（.env 亦兼容）。
    • 补充互译词典：编辑 data/bilingual.json（{"pairs": [["英文","中文"], …]}）。

    AI 设置

    配置大模型用于论文元数据精修（标题/摘要/作者/关键词）；未配置时自动使用本地规则拆解。

    AI 在哪些环节生效

    • 在「文库 → 添加论文」上传 PDF / TXT / ZIP 时，勾选 AI 精修元数据，由模型补全/修正标题、摘要、作者、年份与关键词。
    • 调用失败或未配置时自动回退规则拆解，不影响入库与检索。
    • 配置保存后立即生效并持久化；重新安装应用前的旧数据不受影响。
